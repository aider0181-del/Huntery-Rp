
# Huntery RP

Полноценная 3D RolePlay игра для Android.

## Основные возможности
- Большой открытый город Hunter City
- Машины и мотоциклы
- Инвентарь
- Наличные и банковские счета
- Покупка домов и квартир
- Работа строителем
- Работа дворником
- Полиция
- Больница
- МЧС
- Онлайн-игроки
- Чат общения

## Engine
Unity 3D

## Platform
Android
